1. System overview

The East Forsyth Band website is a public community site plus a private Content Management System (CMS) at /admin. Production runs on Cloudflare Pages with a Worker backend and a D1 database. CMS sessions last 24 hours. Content saved in the CMS publishes to the live public site.

As a Super Admin you can use every CMS tool, manage other users’ roles and permissions, open the Security Audit Log, preview the site during maintenance mode, and download this guide.

2. Roles

RoleHow it is setWhat it means
Super AdminUser Management → Role = Super Admin (role = admin)Automatic access to every permission and every CMS panel. Can delete meeting minutes, open Security Log, download this guide, grant Super Admin to others, and preview the public site during maintenance.
EditorRole = EditorAccess only to tools granted by global permissions and page-level checkboxes. Cannot open Security Log or this Website Guide. Cannot delete minutes.

Only an existing Super Admin can create or promote another Super Admin. Editors with users permission can manage other editors, but cannot assign the Super Admin role.

3. What every logged-in user can do

These items are available to any active CMS account (Editor or Super Admin), even with no extra permissions:

  • Dashboard (permission-filtered cards)
  • Staff Email — compose and send rich-text mail to CMS users (with attachments)
  • Change Password and Log Out
  • Calendar Events — view only — browse events by month (‹ / This month / ›). Create, edit, and delete still require calendar permissions
  • Meeting Minutes — view / print — open minutes by date. Add / edit / upload require secretary permission; delete is Super Admin only

5. Security Audit Log (Super Admin only)

Open from Dashboard (red–black Security Log card, always last) or Manage → Security Log.

  • Who: Super Admin role only. Cannot be granted to editors.
  • What you can do: View, filter, paginate (5 entries per page with « ‹ Page N of M › »), and download/print the full PDF export.
  • What you cannot do: Edit, delete, or clear log entries — even as Super Admin. The vault is append-only.
  • Storage: Encrypted at rest (AES-256-GCM) with SHA-256 integrity checks in D1 (admin_audit_log). Isolated from public pages, logos, and site content.
  • Access logging: Opening the first page of the preview writes security.log.view. PDF export writes security.log.export. Pager clicks do not write a new view entry.

5.1 What gets logged (examples)

  • Successful and failed logins (login.failed includes IP)
  • Logouts
  • CMS mutations (pages, users, events, sponsors, staff, boosters, minutes, photos, contact topics, site settings, etc.)
  • Staff Email sends (separate mail audit detail)
  • Security log view / PDF export

Sensitive fields (passwords, tokens, raw attachments) are redacted from stored metadata.

6. CMS Dashboard & navigation

After login, Dashboard cards appear based on permissions. Super Admin cards include:

  • Website Guide (this PDF) — Super Admin only
  • Checkout — Square officer payments
  • Staff Email
  • Meeting Minutes
  • Sponsors tools, Directors & Staff, Ensemble, Booster Members
  • Contact Form, User Management, Social / Facebook, Calendar Events
  • Security Log — always pinned last

Left nav mirrors those tools. Mobile uses the Menu bar with the same permission filtering.

7. CMS tools (detailed)

7.1 Staff Email

Who: Any logged-in user.

Rich-text compose, CMS recipients, optional extra addresses, attachments (up to 5 files / ~4 MB each / ~10 MB total). Reply-To uses the sender’s username (should be a real email). Delivery uses Resend when configured.

7.2 Pages (visual editor)

Who: pages or page:<slug>.

Live preview editing with bold/italic/underline/color/size. Super Admins / pages users can change page settings. Unsaved changes warn before leaving. Page shortcuts appear under Pages for site admins.

7.3 Directors & Staff

Who: staff or directors page access.

Add/edit/delete people with photo, name, role, bio; drag to reorder the public directory.

7.4 Ensemble

Who: page:ensembles or pages.

Floating editor for Ensembles page body content under the hero.

7.5 Band Boosters → Booster Members

Who: boosters or Boosters page access.

Officer/member directory with photo, role, bio, drag reorder.

7.6 Band Boosters → Meeting Minutes

ActionWho
View / printAny logged-in CMS user
Add Minutes / Upload .docx / editminutes (Meeting Minutes Secretary) or Super Admin
DeleteSuper Admin only
  • Pick a meeting date to open the document in the viewer (mobile uses a compact full-page viewer with Back).
  • Secretaries use Add Minutes (letterhead editor) or Upload .docx (up to about 8 MB). Meeting date can come from the document Date field or filename.
  • Non–Super Admin editors may edit only within 10 days of the meeting date (not from upload time).
  • Canceling Add/Edit confirms discarding unsaved changes.
  • Minutes are staff-only — never published on the public Boosters page.

7.7 Calendar Events

ActionWho
Browse by monthAny logged-in CMS user
Create / edit own / delete ownevents
Edit / delete anyevents:manage or Super Admin
  • CMS list is filtered by month with ‹ / This month / › controls. Public calendar is unchanged.
  • Supports rich titles/descriptions, repeating series, exceptions, and Boosters meeting placement (non-repeating only).
  • Past events remain in CMS but are hidden from the public Calendar (public shows a limited upcoming set).
  • Create/update/delete also triggers best-effort Notify Me browser push to opted-in visitors.
  • View-only users see a note and no New event form; rows show View only instead of Edit/Delete.

7.8 Sponsors → Manage sponsors

Who: sponsors.

  • Add, edit, delete, reorder sponsors and logos
  • Assign Bronze / Silver / Gold (marquee, fly-in, game-day recognition)
  • Homepage fly-in timing
  • Print / download Gold sponsors PDF sheet

7.9 Checkout

Who: treasurer, president, vice-president, or Super Admin.

Key a Square card payment: payer/entity, description, amount (minimum $1.00), optional internal note. Card data stays with Square.

7.10 Contact Form

Who: contact or Contact page access.

Manage topics and destination emails; check delivery provider status; review Recent Messages (stored even if delivery fails). Clearing historical messages is an admin operations task (database cleanup), not an editor action.

7.11 User Management

Who: users (Super Admin for promoting admins).

Invite flow: New user → email username, temporary password (min 8 chars), permissions → Send Invite / Save. Welcome email points to https://efhsband.org/admin when mail is configured.

7.12 Social / Facebook

Who: site.

Connect the band Facebook Page through Zernio; publish or schedule posts when configured. Calendar Facebook suggestion tools (including ignore) live in this area when enabled.

7.13 Site Settings

Who: site (utility/home link editing may also allow pages or home page access).

Site title, hero text, footer note, logo, maintenance mode, top utility links, footer social links.

Maintenance mode: Public visitors go to /maintenance.html. Super Admins can still open public pages and see a gold Super Admin preview banner. Non–super-admin staff are treated like the public.

7.14 Photos

Who: photos.

Upload/edit/delete/reorder gallery photos (JPG, PNG, WEBP, GIF, SVG; ~2 MB server max / UI ~1.9 MB). Always include alt text. Staff photos and sponsor logos are excluded from the public Home gallery listing.

9. Public payment flows

9.1 Become a Sponsor (Square)

  1. Visitor chooses Bronze, Silver, or Gold (amounts/copy editable in CMS).
  2. Enters business details and optional logo (~2 MB).
  3. Pays by Square card when configured.
  4. On success the sponsor activates in the correct tier; invoice email sends when possible.

Default benefits: Bronze = marquee; Silver = marquee + fly-in; Gold = marquee + fly-in + game-day announcement.

9.2 Donate

From Sponsors and Fundraising — donor name, amount, Square card when configured.

9.3 Officer Checkout (CMS)

Described in §7.9. Requires Square: SQUARE_ACCESS_TOKEN, SQUARE_APPLICATION_ID (or SQUARE_APP_ID), optional SQUARE_LOCATION_ID, SQUARE_ENVIRONMENT.

10. Login, sessions & passwords

  • Login: https://efhsband.org/admin/login
  • Session: 24 hours (HttpOnly Secure cookie)
  • Password minimum: 8 characters
  • Failed logins clear any stale session cookie and are written to the Security Log
  • Change Password is available to every logged-in user

11. Email features

  • Staff Email (internal)
  • User welcome invites
  • Contact form topic routing + Recent Messages in CMS
  • Sponsor invoices from the Boosters invoice address after paid sponsorships

12. Photos & media limits

  • Gallery / logo / staff / booster / sponsor images: JPG, PNG, WEBP, GIF, SVG; ~2 MB
  • Always include alt text
  • Minutes DOCX uploads: up to about 8 MB
  • Staff Email attachments: separate limits (see §7.1)
